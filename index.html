1. Agregar multiplicadores

Escribí o pegá valores separados por espacios, comas o saltos de línea. Ejemplo: 1.07x, 2.35x, 5.10x.

2. Leer una captura

Elegí una captura de pantalla. El navegador intentará leer los números con reconocimiento de texto si la función está disponible. Revisá siempre los valores detectados antes de agregarlos; la lectura puede equivocarse.

4. Historial guardado en este dispositivo

Los datos se guardan localmente en este navegador. Si borrás los datos del navegador o cambiás de dispositivo, pueden perderse.

Cómo interpretar

Estos porcentajes describen solamente las rondas que registraste. No son probabilidades garantizadas para la próxima ronda. Una racha de resultados bajos o altos no permite saber cuándo ocurrirá el siguiente resultado.
JetX Analyzer es una herramienta independiente de registro estadístico. No realiza apuestas ni se conecta a tu cuenta de juego.
